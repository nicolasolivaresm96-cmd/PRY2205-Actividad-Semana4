## Descripción

Actividad formativa correspondiente a la Semana 4, desarrollada en Oracle SQL Developer mediante consultas SQL y relaciones entre tablas.

## Casos desarrollados

1. **Listado de trabajadores:** Consulta de trabajadores según sueldo base, ciudad y tipo de trabajador.
2. **Listado de cajeros:** Análisis de tickets vendidos, montos de ventas y comisiones.
3. **Listado de bonificaciones:** Cálculo de bonificaciones según antigüedad y sistema de salud, considerando cargas familiares y estado civil vigente.
